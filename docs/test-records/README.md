# Hồ sơ kiểm thử

Lưu hồ sơ theo ngày chạy. Mỗi ngày chia thành ba nhóm:

- `scenarios/`: mục tiêu, tiền điều kiện, kết quả mong đợi và kết quả thực tế.
- `results/`: tổng hợp kết quả, số liệu và giới hạn kiểm thử.
- `testers/`: người thực hiện, người yêu cầu và người xác nhận.

Dùng ngày theo múi giờ `Asia/Ho_Chi_Minh`, ví dụ `2026-11-18/`. Không lưu API key, webhook secret, private key, SARIF thô hoặc dữ liệu nhạy cảm.
